# Алгоритм хранения и обновления прогноза

Прогноз хранится отдельно для каждого `region_id`, модели, контрольной точки и
часа. Ряды ECMWF, GFS и ICON не смешиваются в кэше.

## Обработка запроса

1. Определить текущую дату по `primary_timezone` выбранного региона.
2. Удалить из базы строки с `local_date` раньше текущей даты. Текущий день
   сохраняется целиком, чтобы суточные графики и агрегаты оставались
   сопоставимыми.
3. Прочитать из базы прогноз от текущей даты до `+6 дней`.
4. Если все точки, даты и модели присутствуют и моложе
   `FORECAST_CACHE_TTL_SECONDS`, вернуть данные из базы без запроса Open-Meteo.
5. Если полный набор есть, но срок свежести истёк, немедленно вернуть сохранённый
   прогноз и обновить его в фоне. Интерфейс показывает, что идёт фоновое
   обновление, и периодически проверяет его завершение.
6. Если набор частичный, вернуть доступные сохранённые модели и в фоне запросить
   только отсутствующие модели и диапазон отсутствующих дат.
7. Если регион запрашивается впервые, дождаться первичного получения данных и
   сохранить результат. Одновременные запросы одного региона объединяются одним
   серверным lock и не создают дублирующие обращения к Open-Meteo.

## Переход на следующий день

После смены локальной даты вчерашний день удаляется. Шесть оставшихся будущих
дней уже находятся в базе, поэтому для каждой модели запрашивается только новый
седьмой день. Если данные модели устарели по TTL, её будущий семидневный прогноз
обновляется полностью: прогноз существующих часов может измениться после нового
запуска метеомодели.

## Ошибки и объём хранения

- Ошибка одной модели не удаляет успешно сохранённые данные других моделей.
- Сырые ответы Open-Meteo по умолчанию не сохраняются
  (`STORE_RAW_RESPONSES=false`), потому что нормализованные почасовые записи уже
  содержат используемые продуктом значения.
- `FORECAST_RETENTION_PAST_DAYS=0` означает удаление всех дней до сегодняшнего.
  Значение можно увеличить, если позднее понадобится история.
- Кнопка ручного обновления принудительно обновляет будущие семь дней выбранного
  региона.
