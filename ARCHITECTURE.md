# Архитектура

React-клиент получает агрегированные данные из FastAPI. Сервис прогноза загружает
контрольные точки, проверяет SQLite TTL-кэш и выбирает deterministic mock либо три
независимых Open‑Meteo адаптера. Адаптеры одним циклом загружают максимальный
семидневный горизонт, пакетно получают координаты и приводят ответы к
`ForecastRecord`. Селекторы `today`, `3d` и `7d` фильтруют один нормализованный
набор. Только после нормализации статистический слой выравнивает ряды по точке и
UTC-времени, строит дневные модельные показатели, а затем консенсус и агрегаты
периода.

SQLite хранит исходные JSON-ответы и нормализованные записи за семь дней с началом,
окончанием и часовым поясом загрузки. HTTP routes не содержат расчётов. JSON со
списком точек можно заменить загрузчиком сетки внутри GeoJSON без изменения
provider- и statistics-слоёв.
