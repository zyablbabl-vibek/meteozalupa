# Вклад в проект

Создайте отдельную ветку, запускайте проверки обеих частей приложения и описывайте
изменения статистических правил в pull request. Новые провайдеры должны наследовать
единый адаптер и возвращать `ForecastRecord`. Изменения API должны сохранять
понятные русские сообщения об ошибках.
