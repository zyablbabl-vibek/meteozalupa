# Контрольные точки

Список содержит 20 населённых пунктов, распределённых по Амурской области. Координаты
WGS84 сверены 30 июля 2026 года по карточкам населённых пунктов в
[GeoNames](https://www.geonames.org/) и [OpenStreetMap](https://www.openstreetmap.org/).
Координаты описывают центры населённых пунктов, а не узлы модельных сеток.

Выборка не является непрерывной картой региона. Архитектура изолирует загрузку точек в
JSON, поэтому в будущем источник можно заменить сеткой, построенной внутри
GeoJSON-полигона области.
