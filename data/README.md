# Данные

Актуальные контрольные точки находятся в `regions/`, единый registry —
`regions/regions.json`. Источники, лицензии и ограничения описаны в
`regions/SOURCES.md`.

`amur_points.json` сохранён как исторический набор первой версии и больше не
используется приложением. Он не является источником универсальной региональной
логики.

Папка `geo/regions/` предназначена для опубликованных GeoJSON с понятной
лицензией. Отсутствующая граница не заменяется самодельным полигоном.
